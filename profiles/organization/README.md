# Organization profiles

Reserved for organization profiles: an organization's terminology, constraints,
gates and disclosure rules, kept apart from research-method, narrative and
publication rules (see `docs/architecture/monorepo-structure.md`).

No organization profile exists yet. MISCO-specific rules currently live in the
`misco` narrative and publication profiles. Moving the organization-level
parts here is tracked with the MISCO isolation work in #495.
