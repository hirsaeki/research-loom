`SYNTHETIC_TEST_ONLY`。対象は公開可能な3ケースの縮約原稿のみ。
#465の制作契約はPR #470、#466の現稿bindingはPR #472で統合済み。
この記録はそれらと有限の除去比較を結び、採用できる範囲を明示する。
一般的な読者効果、独立人間評価、実運用の離脱率改善は実証していない。

## 制作手順の採用判断

| 手順 | 判断 | 根拠と制限 |
| --- | --- | --- |
| 読者の判断課題から問いへ入る | 維持 | 基準版にも機能していた。追加Entry指示の独立した改善効果は未確立。読者の入口を確認する短い制作手順として使う |
| 中盤の区別・発見・次の問いを接続する | 維持、重複説明を簡略化 | 反復留保が人間の読む意欲を阻害した。接続詞や短さで合否を決めず、どの理解が進むかを本文で確認する |
| 入力済み提言を最初の判断へ戻す | 維持 | 両版とも概ね機能し、追加Return指示の上乗せは未確立。提案を決定済みに変えない点検も続ける |
| 段落の役割競合を直す | 採用範囲を維持 | ユーザー合意の契約。必要な限定・対比は同居できる。無関係な免責・反復が段落を中断する場合に具体的改稿へ返す |
| 留保の配置 | 内容に応じた限定採用 | 対論・反対結果は本論、共通限界は方法・考察、補足は注記・付録。注記への一律移動は非採用。注記の増加自体も読む負担になり得る |
| 新しいProfile規則・採点・常設評価系 | 追加しない | 既存規則との重複があり、追加機構の効果を示す根拠なし。既存Feedbackと任意の対象付きrecordで足りる |
| 主観品質や未実証を理由とする保存停止 | 非採用 | 草稿・部分改稿を継続し、所見を実際の本文編集へ返す。研究採択・公開承認の権限は変えない |

## 完了と呼べる範囲

これは**制作手順・具体的編集・対象一致の限定的な受入**である。
初回稿、負例、意味所見、読者1名の回答、モデルとの不一致、公開Host往復を残し、
改善が一様でないことも含めて判断できる状態にする。

独立した初読者比較、十分な長さの論文、実際の継続選択、実運用の離脱率、
各手順の因果的な効果、Profile全体の意味審査は未実施。
#467／Epicの受入範囲は上記の制作手順・具体的編集・対象一致までに限定する。
「読ませる効果を一般的に実証した」とは記載しない。
実論文で対象読者がどう読むかは、この合成試験から推定しない。
既に行ったユーザー確認を繰り返すことや、新しい人間評価者の募集を今回の自動停止条件にはしない。
