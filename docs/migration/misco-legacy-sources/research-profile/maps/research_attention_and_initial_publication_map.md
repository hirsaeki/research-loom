**May determine method:** false  
**May determine answer:** false

## 1. このMapの意味

本Mapは、現行の第1～8章・節構成から、今後も見落としたくない研究Attentionと、最終報告書の初期予想構成を蒸留したものである。

二つを混同しない。

- **Attention:** 研究中に検討対象から黙って消してはならない論点。不要・対象外とする場合は理由をResearch Stateへ残す。
- **Initial Publication Location:** 現時点で読者へ説明するなら自然と予想する配置。研究結果に応じて移動、統合、分割、改称、廃止できる。

したがって、**Attentionは比較的安定、Chapter TreeはPROVISIONAL**である。章・節が存在するからSurvey／Delphi／Case等を実施してはならず、方法はEvidence Gapから選ぶ。

## 4. Map update rule

- Attentionの削除・対象外化はResearch Stateに理由を残し、重大なScope変更はHuman Decisionへ送る。
- Chapter/Sectionの移動、統合、分割、改称はPublication Map Deltaとして更新できる。
- Initial Publication Mapが方法選択を起動してはならない。
- Research Findingを章構成へ合わせて歪めてはならない。
- Publication WriterはこのMapをReader-facing routingに利用できるが、研究結果のEvidenceとして引用してはならない。
