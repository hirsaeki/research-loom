# 08_EDITORIAL_QA_CHECKLIST

このチェックは文章・編集・正式表示だけを対象とする。**根拠が本当に主張を支えるか、因果と言えるか等の正否判定は別の確認へ送る。**

## A. 研究判断を新規生成していないか

- [ ] RQ、仮説、分類、モデル、枠組み、提言を入力なしに作っていない。
- [ ] 支持・補強・修正・判定不能等をWriterが新規判定していない。
- [ ] 新しいFinding、因果、一般化、成功要因、期待効果を作っていない。
- [ ] 提言数・柱数・分類数・段階数をStyle側で決めていない。
- [ ] Evidence不足を文章の勢いで補完していない。

## B. 章・節・段落の接続

- [ ] 長文では序論末に構成または流れが短く示されている。
- [ ] 章頭で、必要な場合に前章の到達点と本章の役割が接続されている。
- [ ] 章末で、新しい結論を作らず必要な要点・限定・次章接続が示されている。
- [ ] 要約・章末・提言・終盤総括の反復に機能差があり、単なる言い換え連打になっていない。

## C. 観測・解釈・不確実性

- [ ] 観測と承認済み解釈が文章上区別されている。
- [ ] 推論・仮定・推定が事実のように書かれていない。
- [ ] 断定の強さが研究側で承認済みの強度を超えていない。
- [ ] 承認済みの限界・不確実性・適用範囲が消えていない。
- [ ] 未承認の代替説明をWriterが追加していない。

## D. 図・表・定量結果

- [ ] 図表が突然置かれていない。
- [ ] 図表番号・題名・出典・必要な読み方が揃っている。
- [ ] アンケート・定量図表のn、分母、複数回答等が必要範囲で明示されている。
- [ ] 図表を全数値・全セル読み上げしていない。
- [ ] 図表から新しい解釈・限界・因果を発見していない。
- [ ] カラー図表を使用する場合、承認済みのカラー使用条件を満たし、白黒表示でも識別できるかを確認している（HD-04=Bの条件付きQA）。

## E. ヒアリング・事例

- [ ] 選定理由・研究上の役割が必要範囲で示されている。
- [ ] 事実・発言と承認済み評価が区別されている。
- [ ] 匿名化・社名開示・原稿確認等の公開条件を守っている。
- [ ] 複数事例の比較軸・横断結果をWriterが作っていない。
- [ ] 少数事例を代表例として過剰一般化していない。

## F. モデル・枠組み・提言

- [ ] モデル・枠組みは研究側に存在するときだけ出している。
- [ ] モデル図を置いた場合、承認済みの要素・関係を本文で説明している。
- [ ] 提言は研究側に存在するときだけ出している。
- [ ] 提言前に既出分析との接続がある。
- [ ] 提言箇所で新しい主要根拠を追加していない。
- [ ] 命令形・感嘆符で根拠以上に強く見せていない。

## G. 用語・構造の混入防止

- [ ] RQ、Findings、IMRaD、Literature Review等をMISCO標準の必須構造として追加していない。
- [ ] Research State、Evidence、Claim strength等の内部語が本文の必須見出し・語彙として露出していない。
- [ ] 過年度のSource、Case、モデル名、提言、分類、固有章構成に依存していない。

## H. 正式書式

- [ ] 現行正式仕様の優先順位を守っている。
- [ ] 正式見出し階層、図表題、出典、脚注、頁付け等が利用可能な正式設定に一致している。
- [ ] 頁設定・書体・字下げ等はHD-01=Aに従い、現行正式仕様原本を正本としている。
- [ ] 参考文献一覧の配置はHD-02=Aに従い、現行正式仕様原本の方針を適用している。
- [ ] 長い raw URL はHD-03=Bに従い、人間承認済み統一URL表示プロファイルを適用している。
- [ ] 必要な正式原本・メタデータ・URL表示プロファイルが不足する場合、推測せず `HUMAN_DECISION_REQUIRED` にしている。

## I. 別QAへ送る項目

次はPublication Style QAでは判定しない。

- 根拠がその主張を本当に支持するか。
- 因果と言ってよいか。
- 引用元の支持範囲を超えていないか。
- 研究上の問い・分析結果・主張の対応が研究として成立しているか。

必要時は `SEND_TO_EVIDENCE_CLAIM_QA` とする。
