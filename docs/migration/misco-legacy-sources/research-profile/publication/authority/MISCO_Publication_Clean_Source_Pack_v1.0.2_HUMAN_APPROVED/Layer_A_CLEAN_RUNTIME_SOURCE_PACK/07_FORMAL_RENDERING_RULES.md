# 07_FORMAL_RENDERING_RULES

## Formal source priority

正式書式と観察された書き方が食い違う場合の優先順位は次の通り。

1. **現行のMISCO固有正式文書仕様**
2. **三井業際研究所の一般マニュアル**
3. 過去に観察された書き方は正式仕様を上書きしない

Human Reviewで正式設定ポリシーは確定した。HD-01=Aにより具体設定値の正本は現行正式仕様原本とし、Source Pack自身は値を推測しない。原本・必要メタデータ・承認済み表示プロファイルがruntime入力として不足する場合は、方針未決ではなく入力不足として `HUMAN_DECISION_REQUIRED` とする。

| Requirement | Scope | Exceptions | Human metadata needed | Formal source priority |
|---|---|---|---|---|
| 頁設定・本文/見出し書体・字下げ等は現行正式仕様に従う | 文書全体 | 正式仕様改訂時は最新版 | `formal_spec_profile`（HD-01=A: 現行正式仕様原本を正本とする） | 1→2 |
| 正式見出し階層を使い、独自の平行階層を増やさない | 見出し・目次 | 現行仕様が明示許容する場合のみ | 正式見出し設定 | 1→2 |
| 本文は原則「である調」 | 本文 | 挨拶機能、謝辞、提言見出しは別機能 | 出力部位 | 1→2 |
| 要約は現行MISCO固有要領に従い2頁以内を基準とし、経営への承認済み提言を含める | 要約/要旨 | 提言数は固定しない。承認済み提言がなければ研究側へ戻す | 要約の要否、承認済み提言 | 1 |
| 本文50〜60頁を編集目標とし、研究内容上必要な場合は70頁程度まで許容 | 全体本文 | 超過時は圧縮・重複削減・付録移管を先に検討 | 全体出力時のみ | 1 |
| 図題は下、表題は上。正式番号で参照する | 図表 | 添付資料は別仕様の可能性 | 図表番号・題名 | 1→2 |
| 本文中の図表参照は図表番号で行い、位置依存表現だけにしない | 図表参照 | なし | 図表番号 | 1→2 |
| 外部図表・引用は出典を近接表示し、正式な書誌情報を示す | 外部資料 | 長い raw URL はHD-03=Bの人間承認済み統一URL表示プロファイルに従う | 著者、題名、発行元、年、頁等。必要時はURL表示プロファイル | 1→2 |
| 補足説明・用語解説は原則Word脚注 | 脚注 | 現行正式仕様が別形式を明示した場合 | 脚注内容 | 1→2 |
| 目次・本文・添付資料の頁付けと研究会種別等による外側の構成は現行MISCO要領に従う | 文書外形 | 研究会種別により分岐 | `research_group_type`、正式仕様プロファイル | 1 |
| ヒアリング・社内情報は掲載可否・社名開示・原稿確認等を満たす | 公開統制 | 公開情報のみは別扱い | `permission_status` | 1 |

## HUMAN REVIEW DECISIONS APPLIED — formal configuration policy

以下は既存Style Ruleの追加ではなく、Human Reviewで確定した正式設定ポリシーの反映である。

1. **HD-01=A — 具体的な頁設定・書体・字下げ等**：現行正式仕様原本を正本とする。Source Packから推測しない。runtimeで原本または必要設定が未提供なら `HUMAN_DECISION_REQUIRED`。
2. **HD-02=A — 参考文献一覧の最終配置**：現行正式仕様原本の配置方針をそのまま適用する。Source Pack独自の配置既定値は作らない。
3. **HD-03=B — raw URLのreader-facing表示**：人間承認済みの統一URL表示プロファイルを適用する。具体方式はSource Packが創作せず、runtime入力として与える。未提供なら `HUMAN_DECISION_REQUIRED`。
4. **HD-04=B — カラー図表QA**：カラー図表を使用する場合だけ、承認済みのカラー使用条件と白黒表示時の識別性を確認する条件付きQAとする。
