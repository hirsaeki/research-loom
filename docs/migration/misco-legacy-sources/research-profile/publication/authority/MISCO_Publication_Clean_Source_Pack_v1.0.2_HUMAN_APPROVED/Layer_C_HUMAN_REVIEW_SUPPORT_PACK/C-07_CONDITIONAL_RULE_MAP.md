# C-07 CONDITIONAL RULE MAP

## 毎回確認するもの

- 研究側から承認済みの情報だけを使っているか。
- Writerが新しい解釈、因果、分類、モデル、提言を作っていないか。
- 断定の強さが承認済み内容を超えていないか。
- 承認済み限界・不確実性を消していないか。
- 提言数・分類数・段階数・章順を文章側で固定していないか。
- 一般的な研究論文の型をMISCO標準として追加していないか。
- 正式書式は現行正式仕様を優先しているか。不明な設定を推測していないか。

## 必要な場合だけ使うもの

| 研究側に存在する要素 | 使う書き方 | 存在しない場合 |
|---|---|---|
| 外部資料 | 資料内容と本研究での使用目的を接続 | 資料整理該当する書き方を使わない |
| アンケート・定量結果 | n等の読み方、主要値、承認済み解釈・限定を説明 | 定量結果該当する書き方を使わない |
| ヒアリング・事例 | 選定理由、事実、承認済み評価を分けて説明 | 事例該当する書き方を使わない |
| 複数事例＋承認済み比較軸 | 共通軸で記述し、承認済み横断結果を説明 | 比較軸・横断結果を作らない |
| 仮説・研究上の問い＋承認済み判定 | 支持・修正等を承認済み強度で表現 | 仮説や研究上の問いを作らない |
| 承認済み分類・上位整理 | 形成理由・適用範囲を説明 | 分類を作らない |
| 承認済みモデル・枠組み | 形成理由・構成・関係・使い方を説明 | モデルを作らない |
| 承認済み提言 | 既出分析からつなぎ、存在する要素を説明 | 提言を作らない |
| 承認済み限界・不確実性 | 結果近傍・考察・終盤等で見えるようにする | 新しい限界を作らない |

**重要**: 条件付きルールは、文章側が研究要素を作るきっかけではない。研究側にその要素が承認済みで存在するときだけ呼び出す。
