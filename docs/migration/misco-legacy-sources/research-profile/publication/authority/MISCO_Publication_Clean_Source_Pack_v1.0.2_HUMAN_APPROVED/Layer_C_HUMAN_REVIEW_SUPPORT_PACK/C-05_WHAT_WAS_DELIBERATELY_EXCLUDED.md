# C-05 WHAT WAS DELIBERATELY EXCLUDED

## 過年度論文の研究テーマ

将来の文章ルールではなく、その年度固有の研究内容だから。

## 過年度の結論

将来研究の結論を先取りする危険があるため。

## 過年度の仮説

仮説の存在自体を将来研究へ強制しないため。

## 過年度のモデル

モデル形式や構成をMISCO標準成果物にしないため。

## 過年度の分類数

分類数は研究内容そのものであり、文章側で固定してはいけないため。

## 過年度の提言内容・提言数

将来研究の行動内容と件数を過去から輸入しないため。

## 過年度の事例

特定事例を成功例・標準例として再利用しないため。

## 過年度の出典・情報源

現在の研究側で承認された資料だけを使うため。

## 特定論文の章構成

研究方法・成果物に依存するため、将来の章順を固定しない。

## 一般的な研究論文の書き方から自動追加したルール

再凍結報告書に根拠がないルールはMISCO Styleとして追加できないため。

## 研究上の問いやモデル等を必須とする考え方

研究側に存在しない要素を文章側から要求・生成しないため。
