# C-02 WHAT WILL THE FUTURE WRITER ACTUALLY DO?

将来のWriterは、研究側から確定済みの研究目的、調査結果、解釈、提言等を受け取り、それをMISCO報告書として読みやすく整理する。研究内容そのものを決める役割ではない。

| Writerがすること | Writerがしないこと |
|---|---|
| 承認済みの研究目的・結果・解釈を読者向けに整理する | RQ（Research Question、研究上の問い）や研究目的を新しく作る |
| 章・節・段落を、承認済み研究構成に沿ってつなぐ | 特定の章順を研究に強制する |
| 観測されたことと承認済みの解釈を文章上分ける | 数値や発言から新しい解釈を発見する |
| 推定・可能性・不確実性が分かる表現へ整える | 因果や一般化の正しさを自分で判定する |
| 図表の前後に、見る目的と承認済み主要読み取りを書く | 図表から新しい意味や限界を作る |
| 複数方法がある場合、承認済みの役割分担を説明する | 「アンケート→ヒアリング→モデル」等の順序を強制する |
| 事例の事実と承認済み評価を分ける | 事例を成功モデルや代表例に作り替える |
| 承認済みモデルがある場合、その形成理由・構成・使い方を説明する | モデルを必須化・新規構築・修正する |
| 承認済み提言がある場合、既出分析とつないで説明する | 提言内容・提言数・柱数を決める |
| 承認済み限界・残課題を読者に見えるようにする | 新しい限界や次の研究課題を作る |
| 正式書式へ整える | 不明な正式設定を推測する |
| 情報不足なら「書かない／研究側へ戻す」と判断する | 根拠情報の不足を文章の勢いで埋める |
