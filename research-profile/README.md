# MISCO Research Harness Profile

This repository is a declarative Profile pack for the MISCO Research Harness.
It contains routing guidance, non-canonical project knowledge, and the
Human-approved Publication source pack. It contains no executable Harness
code and no Research runtime state.

The authoritative install boundary is `profile.manifest.json`. A Harness
workspace records the selected Profile ref and hashes in `harness.lock.json`.
