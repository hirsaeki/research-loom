# C-03 RULE DECISION DIGEST

## 背景・研究目的

- **何をルール化するか:** 背景の羅列で終えず、承認済みの未解決問題から研究目的へ絞る。
- **なぜ必要か:** 研究の入口を読者が理解できるため。
- **必須か／条件付きか:** 通常使用。ただし問題や目的が承認済みであること。
- **使わない場合:** 承認済み関係がない場合は作らない。
- **人間が注意して確認すべき点:** Writerが「研究上のギャップ」を新しく作っていないか。

## 章のつなぎ

- **何をルール化するか:** 章頭で前章の到達点と本章の役割を短く示し、必要な章末では次へ接続する。
- **なぜ必要か:** 長い報告書で読者が現在地を見失わないため。
- **必須か／条件付きか:** 通常使用。短い文書・第1章等は条件付き。
- **使わない場合:** 短章では省略可。
- **人間が注意して確認すべき点:** 前章を再要約し過ぎていないか、新しい結論を作っていないか。

## 段落

- **何をルール化するか:** 長い説明では段落冒頭に主題を置く書き方を選択肢として使う。
- **なぜ必要か:** 読者の位置把握を助けるため。
- **必須か／条件付きか:** 条件付き。毎段落の必須ルールではない。
- **使わない場合:** 短い説明や定義では不要。
- **人間が注意して確認すべき点:** 「1段落1機能」等をMISCO標準にしていないか。

## 外部資料

- **何をルール化するか:** 資料内容→本研究との関係→承認済み解釈の順で接続する。複数資料の整理項目は固定しない。
- **なぜ必要か:** 資料の羅列や、資料以上の一般化を避けるため。
- **必須か／条件付きか:** 資料を使う場合のみ。
- **使わない場合:** 資料間関係が未承認なら個別説明まで。
- **人間が注意して確認すべき点:** Writerが共通点・差異を新規発見していないか。

## アンケート・定量結果

- **何をルール化するか:** n・分母等を示し、主要値だけを本文で読み、承認済み解釈・限定へつなぐ。
- **なぜ必要か:** 数値の読み方を失わせず、表の音読を避けるため。
- **必須か／条件付きか:** 定量結果がある場合のみ。
- **使わない場合:** 解釈が未承認なら観測で止める。
- **人間が注意して確認すべき点:** 因果・一般化・支持判定を新規作成していないか。

## ヒアリング・事例

- **何をルール化するか:** 選定理由を示し、事実・発言を先に、承認済み評価を後に置く。
- **なぜ必要か:** 事実と評価の境界を守るため。
- **必須か／条件付きか:** 事例がある場合のみ。
- **使わない場合:** 複数事例比較は承認済み比較軸がある場合のみ。
- **人間が注意して確認すべき点:** 匿名条件・代表性・比較軸を勝手に変えていないか。

## モデル・枠組み

- **何をルール化するか:** 研究側に承認済みモデルがある場合だけ、形成理由・構成・関係・適用範囲を説明する。
- **なぜ必要か:** 図だけでは意味が伝わらず、また成果物形式を先に固定しないため。
- **必須か／条件付きか:** 条件付き。モデルがある場合のみ。
- **使わない場合:** モデルがない研究では使わない。
- **人間が注意して確認すべき点:** モデルをWriterが作成・修正していないか。

## 提言

- **何をルール化するか:** 承認済み提言を既出分析につなぎ、主体・行動・条件・期待効果等の存在する要素を説明する。
- **なぜ必要か:** 提言を根拠から切り離さず、かつ文章側で内容を作らないため。
- **必須か／条件付きか:** 条件付き。提言がある場合のみ。
- **使わない場合:** 専用章・件数・固定ステップは不要。
- **人間が注意して確認すべき点:** 提言数や要素数をStyle側で決めていないか。

## 図表

- **何をルール化するか:** 図表の前に見る目的を示し、後で主要な承認済み読み取りを本文にする。
- **なぜ必要か:** 図表を置いて終わらず、本文と視覚情報をつなぐため。
- **必須か／条件付きか:** 図表がある場合のみ。
- **使わない場合:** 単純定義表は前後説明を短縮可。
- **人間が注意して確認すべき点:** 全セル読み上げ、新しい解釈の発見がないか。

## 文体・書式

- **何をルール化するか:** 本文は原則である調。正式階層、図表題、出典、脚注等は正式仕様を優先する。
- **なぜ必要か:** 共同編集と正式提出の一貫性を守るため。
- **必須か／条件付きか:** 正式出力では必須。
- **使わない場合:** 正式設定値がない場合は推測しない。
- **人間が注意して確認すべき点:** 文章の慣行と正式要件を混ぜていないか。

## 内容固定を防ぐルール

- **何をルール化するか:** 提言数・分類数・段階数・モデルの有無・章順等を文章側から固定しない。
- **なぜ必要か:** 過年度研究の内容を将来研究の型にしてしまうことを防ぐため。
- **必須か／条件付きか:** 毎回確認。
- **使わない場合:** なし。
- **人間が注意して確認すべき点:** 「MISCOでは常に〜」という暗黙前提が残っていないか。
