# Rhetorical Pattern Selector

Patterns are conditional transforms, never a mandatory manuscript template. Select only when their approved-input conditions are met.

| Pattern | Use when | Reader-facing sequence | Do not infer |
|---|---|---|---|
| PAT-01 Background → purpose | approved background/problem/scope/purpose relation exists | background → relation to target → purpose | causal gap or new problem |
| PAT-02 External material organization | multiple approved sources + approved relation/use exist | necessary relation → use in this study | new source relationship |
| PAT-03 Purpose connection | approved remaining problem + purpose + method/scope | remaining problem → purpose → supplied method/scope | conclusion in the purpose |
| PAT-04 Method introduction | approved method/target/period/constraints/roles | observation target → method → target/period → constraints → method role | validity or new RQ/hypothesis |
| PAT-05 Figure/table introduction | approved figure/table + what reader should inspect | viewing purpose → reading notes → figure/table | new interpretation |
| PAT-06 Quantitative reading | approved numbers + interpretation/limits/next link | principal values → approved interpretation → approved limit → next link | causal/general claim, whole-cell narration |
| PAT-07 Case description | approved case facts + role/selection + permission | role → facts/quotes → background → approved interpretation | generalization or unapproved interpretation |
| PAT-08 Contrary result/exception | contrary observation exists; interpretation/revision only if approved | mismatch → approved meaning/impact → approved revision | writer-selected repair |
| PAT-09 Limit/uncertainty | approved scope/constraint/unresolved issue exists | what can/cannot be said → effect → residual issue | new limitations/research plan |
| PAT-10 Higher-level organization | approved classification/synthesis already exists | formation reason → approved organization → scope | new categories/count |
| PAT-11 Model introduction | approved model/components/relations/reason/scope exist | formation reason → purpose → components → relations → scope | new model/elements |
| PAT-12 Model revision | approved old/revised model + changes/reasons exist | old model → mismatch → approved change → residual uncertainty | new revision/definition |
| PAT-13 Cross-case synthesis | approved comparison axes/results/range exist | common/different/exception → range → supplied next meaning | comparison discovery/generalization |
| PAT-14 Recommendation bridge | approved recommendation + evidence link/scope exists | prior analysis arrival point → recommendation bridge | new evidence/implication |
| PAT-15 Recommendation body | approved recommendation and supplied actor/action/condition/effect exist | connect available elements in content-appropriate order | fixed element count/order/effect |
| PAT-16 Chapter opening | approved structure + prior arrival point + current role exist | prior arrival point → current chapter role → optional sequence | invented prior conclusion |
| PAT-17 Chapter closing | approved chapter arrival point/limit/next link exist | arrival point → limit → next use | new result/next agenda |
| PAT-18 Final synthesis | approved end-state elements exist | select only existing purpose/results/recommendations/limits/issues | new practical implication/future prediction |

## Navigation rules

- Introduction must not end at “this topic is important”; connect to the approved unresolved problem and purpose.
- When moving from external conditions to an internal/organizational issue, use the approved relation as a bridge.
- Introductions may preview structure/analysis flow if approved structure exists.
- Chapter openings should be short; chapter closings should not create new conclusions.
- Avoid repeated paraphrase of the same claim inside a section. Repetition is justified only by function boundaries such as summary, chapter close, recommendation, or final synthesis.
- Connection words must accurately reflect contrast, inference, supplementation, or other logical relations.
